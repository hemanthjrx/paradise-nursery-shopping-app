# Paradise Nursery Shopping Application

A React and Redux shopping-cart application for Paradise Nursery, an online houseplant shop.

## Features

- Landing page with Paradise Nursery branding and a Get Started button
- Three plant categories with six plants in each category
- Add-to-cart buttons that disable after a plant is added
- Dynamic shopping-cart count in the navigation bar
- Quantity increase, decrease, and item removal controls
- Per-item totals and complete cart total
- Checkout button with a Coming Soon message
- Continue Shopping button

## Built With

- React
- Vite
- Redux Toolkit
- React Redux
